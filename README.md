## Search bar vs checkout: where each code actually goes

SHEIN runs two completely different code mechanisms, and entering a code in the wrong place produces nothing.

**For search bar codes:**

1. Install the SHEIN mobile app and sign in with a **new account**.
2. Type the code (say, LY573) into the app's top search bar and hit enter — the same place you'd search for products.
3. A campaign page or popup appears with the coupon bundle. Tap "Collect all" while signed in, and the coupons land in your account's coupon wallet.

**For checkout codes:**

1. Add items to your cart and go to checkout.
2. On mobile, find the coupon field under Coupons → SHEIN Coupon. On desktop, it's in the price summary on the right, labeled Promo Code.
3. Paste the code and apply. Codes like AFFIL30 won't do anything until your cart passes $29.

If you type a search bar code into the checkout promo box, you'll get an "invalid code" error. If you type a checkout code into the search bar, you'll get search results for the code text itself. Neither means the code is expired — it just means it went in the wrong slot.

## Why your SHEIN code "isn't working"

There are usually four specific reasons, and none of them involve bad luck.

The most common one: **your account isn't new.** SHEIN verifies new-user eligibility inside the app, and an existing account that types LY573 or any new-user code simply won't trigger the bundle — no error, no popup, nothing. Reinstalling the app doesn't reset this. This single fact explains most "these codes are fake" complaints online.

The second is **entering the code in the wrong place**, covered above.

Third, the code **was posted months ago**. SHEIN rotates these campaigns without announcement, so a screenshot from a TikTok in July may be worthless in October.

Fourth, the code **has conditions the poster didn't mention** — minimum spend, category restrictions, or app-only redemption. The terms shown when you collect the coupon are the binding ones.
